## 一、核心 API 与逻辑流

整体数据流与核心 API 的对应关系：

```
                      ┌─────────────────────────────────────┐
                      │  config.yaml (配置主导)              │
                      │  • data.label.horizon → 标签周期     │
                      │  • quarterly_v2.* → V2窗口/gap/平滑  │
                      │  • model.* → 模型类型和超参数        │
                      └──────────────┬──────────────────────┘
                                     │ 配置驱动所有流程
                                     ▼
因子层输出(02因子库)
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  DataConstructorV1                                           │
│  文件: dataset/data_constructor_v1.py                        │
│  职责: 惰性加载因子 → 计算标签(开盘价) → 截面对齐            │
│  输出: X(DataFrame, MultiIndex), y(Series)                   │
│  注意: label.horizon决定y的计算周期                          │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  QuarterlySplitterV2                                         │
│  文件: dataset/quarterly_splitter_v2.py                      │
│  职责: 按自然季度预计算切分(train/valid/pred + gap)          │
│  输出: [QuarterlySplit]                                      │
│  注意: 每个季度一个固定模型                                  │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  QuarterlyTrainerV2                                          │
│  文件: training/quarterly_trainer_v2.py                      │
│  职责: 遍历季度 → 构造数据 → 训练 → 预测 → 保存结果          │
│  输出: predictions.parquet, state/freeze_manifest.json       │
└─────────────────────────────────────────────────────────────┘
    │
    │ (多模型融合，可选)
    ▼
┌─────────────────────────────────────────────────────────────┐
│  fuse_predictions.py                                         │
│  职责: IC加权融合多模型预测 → 生成ensemble预测               │
│  输出: predictions.parquet + smoothed_predictions.parquet    │
└─────────────────────────────────────────────────────────────┘
```

**切分算法核心逻辑**：

```python
def _compute_splits(self):
    for _, period_dates in self.dates.groupby(self.dates.to_period("Q")):
        pred_dates = list(period_dates)
        pred_start_idx = self.dates.get_loc(pred_dates[0])
        
        valid_end_idx = pred_start_idx - self.gap
        valid_start_idx = valid_end_idx - self.valid_days
        train_end_idx = valid_start_idx - self.gap
        train_start_idx = train_end_idx - self.train_days
        
        if train_start_idx < 0:
            continue
            
        splits.append(QuarterlySplit(...))
```

### 1.3 QuarterlyTrainerV2 系列

| 类名 | 文件路径 | 在数据流中的位置 | 核心职责 |
|:---|:---|:---|:---|
| QuarterlyTrainerV2 | training/quarterly_trainer_v2.py | 数据流第3步 | 协调季度训练流程，保存结果，Freeze 增量模式 |

**关键方法**：

| 方法 | 职责 | 调用时机 |
|:---|:---|:---|

| _initialize_splitter() | 初始化季度切分器 | run()内部 |
| _train_period() | 训练单个季度模型 | run()循环中 |
| _predict_period() | 用季度模型预测该季度所有日期 | 模型训练后 |
| _aggregate_predictions() | 合并所有季度预测 | 所有季度完成后 |
| _save_summary() | 生成summary.parquet | 合并预测后 |
| _initialize_freeze_state() | 加载已有冻结状态 | freeze 模式下 |
| _load_or_prepare_frozen_model() | 复用已冻结季度模型 | freeze 模式下 |

**训练流程调用链**：

```python
run()
    ├── _save_config()                    # 保存实验配置
    ├── _initialize_splitter()            # 初始化 QuarterlySplitterV2
    │
    ├── for split in splitter:
    │       └── _train_period(split)
    │               ├── _load_or_prepare_frozen_model(split)
    │               ├── data_constructor.build(split.train_dates)
    │               ├── data_constructor.build(split.valid_dates)
    │               ├── model.fit(X_train, y_train, X_valid, y_valid)
    │               ├── model.save(state_path)
    │               ├── _predict_period(model, split)
    │               └── model.get_feature_importance()
    │
    ├── _aggregate_predictions()          # 合并预测结果
    ├── _save_summary()                   # 生成summary.parquet
    └── _save_manifest()                  # 保存freeze_manifest.json
```

### 1.4 多模型预测融合 (fuse_predictions.py)

**文件位置**: `03模型训练层/fuse_predictions.py`

**功能**: 动态IC加权融合多个V2模型的预测结果。

**V2 核心变化**：
- 不再读取 `smoothed_live_predictions.parquet`
- 不再使用 `split_date`
- 只读取各模型的 `smoothed_predictions.parquet`
- 输出 `predictions.parquet` + `smoothed_predictions.parquet`

**融合算法步骤**：

| 步骤 | 函数 | 说明 |
|:---|:---|:---|
| 1 | `load_model_data()` | 读取各模型 smoothed_predictions |
| 2 | `merge_with_intersection()` | 每天取股票交集 |
| 3 | `rank_standardize()` | 每天截面排名标准化 |
| 4 | `calc_daily_ic()` | 计算每日截面IC |
| 5 | `calc_lagged_weights()` | 计算滞后IC权重 |
| 6 | `fuse_with_weights()` | 动态加权平均 |

**滞后IC权重计算原理**：

```python
def calc_lagged_weights(daily_ic, lag):
    if t < lag:
        w = [1.0 / n_models] * n_models  # 等权重
    else:
        hist_ic = daily_ic.iloc[:t-lag+1].mean()  # 历史IC均值
        hist_ic = hist_ic.clip(lower=0)            # 负IC截断为0
        w = hist_ic / hist_ic.sum()                # 归一化
```

| open.parquet | processed_data/market_data/open.parquet | 计算标签 |

### 2.2 V2 单模型训练输出格式

V2 单模型训练完成后生成**2个主 parquet 文件**：

| 文件 | 说明 | 是否EMA平滑 |
|:---|:---|:---|
| `predictions.parquet` | V2 PIT预测主输出 | ❌ 原始预测 |
| `smoothed_predictions.parquet` | 平滑后V2 PIT预测 | ✅ 固定半衰期EMA平滑 |

V2 **不再生成**：
- `live_predictions.parquet`
- `smoothed_live_predictions.parquet`

**固定半衰期EMA平滑**：

```
halflife = smooth_halflife（默认10个交易日，配置中显式指定）

α = 1 - exp(-ln(2)/halflife)
EMA_t = α × pred_t + (1-α) × EMA_{t-1}
```

与 V1 的区别：
- V1 用整段预测历史动态估计 halflife
- V2 把 halflife 固定为超参数，避免历史平滑值被重算

## 三、开发注意事项（重点）

### 3.1 标签计算方式

V2 继续沿用 open-to-open 标签：

```python
label = open[t + horizon + 1] / open[t + 1] - 1
```

原因：T日收盘后才能拿到完整数据计算因子，实盘只能在T+1日开盘买入。

### 3.2 V2 季度切分中的 Gap

虽然 V2 不再使用 V1 的双重 Gap，但仍保留训练/验证与预测区之间的 Gap：

```python
gap = label_horizon + 1

# 验证集结束必须早于预测季度开始至少 gap 天
valid_end_idx = pred_start_idx - gap
```

这确保验证集标签不会泄露到预测区。

### 3.3 Freeze 增量模式开发注意

**何时使用 --freeze**：
- 每月/每季度增量更新同一个实验
- 只追加新交易日预测，不覆盖历史

**何时换 exp-id**：
- 换模型、换参数、换因子
- 需要重新训练历史区间

**何时使用 --reset-freeze**：
- 明确要重建同一个 exp-id 的冻结状态
- 发现冻结状态损坏或需要重新生成

### 3.4 LambdaRank特殊处理

LambdaRank 标签离散化和 Group 准备逻辑与 V1 相同，按日期分组在每个截面内独立分桶。

## 四、训练配置规范

### 4.1 配置文件结构

```yaml
# ==================== 数据配置 ====================
data:
  factor_paths:
    technical: "02因子库/processed_data/factors/technical"
    financial: "02因子库/processed_data/factors/financial"
  market_data_path: "02因子库/processed_data/market_data"
  price_column: "close"
  open_column: "open"
  label:
    horizon: 20
    use_open_price: true
  st_status_path: "01数据/data/raw_data/st_status.parquet"

# ==================== V2 季度配置 ====================
quarterly_v2:
  train_window: "3Y"      # 训练窗口
  valid_window: "2M"      # 验证窗口
  gap: 21                 # 验证集与预测区间隔（默认 horizon+1）
  smooth_halflife: 10     # 固定平滑半衰期

# ==================== 模型配置 ====================
model:
  name: "lightgbm"        # 或 "lightgbm_rank"
  params:
    objective: "regression"  # 或 "lambdarank" / "huber"
  random_state: 42

# ==================== 训练配置 ====================
training:
  save_models: true
  save_feature_importance: true
  log_level: "INFO"

# ==================== 输出配置 ====================
output:
  experiments_dir: "03模型训练层/experiments"
  predictions_filename: "predictions.parquet"
```

### 4.2 配置文件对比

| 配置项 | default_config.yaml | rank_config.yaml | horizon5_config.yaml | horizon60_config.yaml |
|:---|:---|:---|:---|:---|
| 模型类型 | LightGBM回归 | LightGBM LambdaRank | LightGBM回归 | LightGBM回归 |
| objective | regression | lambdarank | regression | regression |
| horizon | 20 | 20 | 5 | 60 |
| gap | 21 | 21 | 6 | 61 |
| smooth_halflife | 10 | 10 | 10 | 10 |

### 4.3 模型选择建议

| 市场状态 | 推荐模型 | 理由 |
|:---|:---|:---|
| 一般情况 | rank_config.yaml | LambdaRank对极端值更稳健 |
| 收益分布均匀 | default_config.yaml | 简单回归，解释性强 |
| 短周期预测 | horizon5_config.yaml | 预测5日收益 |
| 长周期预测 | horizon60_config.yaml | 预测60日收益 |

## 五、快速命令

### 5.1 V2 基础训练

```bash
# 20d 单模型完整训练
python main_train_v2.py --config configs/horizon20_config.yaml --exp-id qv2_20d_full -y

# 指定 as-of 数据截止日
python main_train_v2.py --config configs/horizon20_config.yaml --exp-id qv2_20d_asof_20260601 --start-date 2020-01-01 --end-date 2026-06-01 -y

# 5d / 60d
python main_train_v2.py --config configs/horizon5_config.yaml --exp-id qv2_5d_full -y
python main_train_v2.py --config configs/horizon60_config.yaml --exp-id qv2_60d_full -y
```

### 5.2 V2 增量更新

```bash
# 首次建立实验
python main_train_v2.py --config configs/horizon20_config.yaml --exp-id qv2_20d_full --start-date 2020-01-01 --end-date 2026-06-01 -y

# 后续每月增量追加（Freeze模式）
python main_train_v2.py --config configs/horizon20_config.yaml --exp-id qv2_20d_full --start-date 2020-01-01 --end-date 2026-07-01 --freeze -y

# 重建同一实验的冻结状态
python main_train_v2.py --config configs/horizon20_config.yaml --exp-id qv2_20d_full --start-date 2020-01-01 --end-date 2026-07-01 --reset-freeze -y
```

### 5.3 V2 多模型融合

```bash
python fuse_predictions.py \
    --exps qv2_5d_full_v2 qv2_20d_full_v2 qv2_60d_full_v2 \
    --base-idx 1 \
    --output-exp qv2_ensemble_5d_20d_60d
```

```bash
python validation/check_quarterly_v2_consistency.py \
    --old-exp qv2_20d_asof_20260506_v2 \
```
